# 武林闲侠传

一款纯前端、开箱即玩的**武侠题材放置（Idle）游戏**。采药采矿、伐木打猎、垂钓江湖，炼丹锻造、烹饪制衣、强化神兵，再入秘境爬塔、轮回转生 —— 按当前数值设计，完整内容可支撑 **2–3 个月** 的游玩消耗。

## 快速开始

```bash
npm install
npm run dev      # 开发预览（默认 http://localhost:5173）
npm run build    # 产物输出到 dist/
```

无后端、无账号体系，游戏存档保存在浏览器 `localStorage`，打开即玩。

## 技术栈

- **React 19 + TypeScript + Vite**
- **Tailwind CSS + shadcn/ui**
- 纯客户端状态引擎（`src/game/engine.ts`），数据与逻辑分离（`src/game/data.ts`）

## 游戏系统

### 生活技能（10 系 · 169 个动作）

| 采集系 | 制造系 |
|---|---|
| 🌿 采药 / ⛏️ 采矿 / 🪓 伐木 / 🏹 打猎 / 🎣 钓鱼 | ⚗️ 炼丹 / ⚒️ 锻造 / 🍳 烹饪 / 🧵 制衣 / ✨ 强化 |

- 各系 **12–16 档**动作，延伸到 Lv.70，同级有并行品类，不是"同一物品分多级"
- 进阶锻造：旧兵器 + 材料 → 下一代神兵，旧装备有处可去
- 分解炉：任意物品分解为市价 40% 铜钱，珍品额外炼出「玄晶」精华
- 炼化转化：玄晶可换顶级材料，部分损耗的道具互换

### 战斗与武学

- 7 条战斗成长线：气血 / 攻击 / 防御 / 剑法 / 拳掌 / 暗器 / 内功
- 多个武学流派，各 **6 招**（最高 Lv.75 解锁）
- 12 种怪物分区分布，离线也有收益结算

### 装备与词缀

- **165 种物品**，武器含刀 / 枪 / 扇 / 斧并行线共 13 把，防具 12 件
- 顶级神兵：屠龙刀 / 方天画戟 / 诛仙剑（ATK 160）、鸿蒙道袍（DEF 140）
- **词缀系统**：装备时随机凝聚 1–3 条词缀（50% / 35% / 15%），8 正 3 诅咒按权重抽取
- 重铸消耗玄晶，15% 概率留下裂痕，3 道裂痕后定型 —— 有随机、有概率、有上限、有惩罚

### 长线玩法

- **秘境爬塔**：层数推进 + 祝福商店（`LAB_SHOP` / `LAB_BLESSINGS`）
- **轮回转生**：达到等级要求后转生，永久提升经验与铜钱收益
- **成就系统**：28 项成就覆盖各系玩法
- **市场 / 任务 / 江湖频道**：铜钱经济循环与每日目标
